# recruit-board

World Athletics age-group top lists (U16 / U18 / U20), rendered as a single
filterable page: season best, personal best, improvement on the athlete's best
before this season, whether they have raced in the US, and whether they are
already an NCAA athlete.

Published from the private `athletics-value` repo — only the rendered HTML lives
here, never the pipeline or the caches.

Not indexed: `robots.txt` disallows crawlers and the page carries
`noindex, nofollow, noarchive`. Most of these athletes are minors, and while
every row is already public on worldathletics.org, a searchable aggregate of
children's names is a different thing from the source.

Source: World Athletics top lists and athlete profiles.
